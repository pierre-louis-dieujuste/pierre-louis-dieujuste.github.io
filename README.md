# Portfolio – Pierre-Louis Dieujuste

Personal portfolio of an aspiring data analyst (SQL & data visualization).

Built with plain HTML, CSS and a little JavaScript. No framework, no build step, no paid service.

## Files

- `index.html` – the content of the page
- `css/style.css` – the design (colors are variables at the top of the file)
- `js/script.js` – mobile menu and footer year
- `images/` – put your images here (optional)

## Run locally

Open `index.html` in a web browser (double-click the file).

## Publish

Hosted for free with GitHub Pages.
